# 极播0.8：统一角色制作与旧项目迁移

0.9界面已重新组织，页面入口以[新版工作空间说明](jibo-0.9-guide.md)为准；本页保留旧模块淘汰与数据兼容说明。

## 功能去向

| 旧功能 | 当前处理 |
|---|---|
| 待机、说话、动作预览 | 角色制作预览，使用同一套角色视频播放器 |
| 语音同步测试 | 角色制作「语音与动画测试」，沿用系统/兼容/本地克隆语音 |
| 正面人物与背景素材 | 「本地建卡素材」上传，或选择已保存的历史人物图 |
| 下载标准动作图、复制提示词 | 「本地建卡素材」内下载人物图、选择动作后复制提示词 |
| 确认用于直播、迁移 | 角色卡验收应用、角色ZIP、项目ZIP |
| 网格绑定、头部关节、衣料遮罩、静图表情形变 | 已淘汰，不再驱动直播；动作和衣物变化来自视频本身 |
| 旧版场景生成、旧动作短片播放器 | 已移除；云端角色生成和视频角色卡是当前入口 |

并非所有旧功能都一一复制：网格形变是此前效果不理想且用户已放弃的路线，视频方案替代其用途，不再保留参数编辑器。

## 现有角色

已有视频角色卡无需重新生成。进入角色制作，选择角色、测试语音及动作，确认并应用，然后到工作台开始彩排。收到礼物播放本卡答谢视频。缺少开心等情绪视频时使用平静说话。

## 只有旧场景或现成视频

1. 在角色制作展开「本地建卡素材」，选择历史人物图，或上传透明正面PNG/纯绿幕人物图。普通带背景原图请使用云端新角色流程；本地入口不会凭空补齐正面或替换人物身份。
2. 可上传独立背景；它会随新建卡保存。选择动作后可复制外部视频生成提示词，或下载人物图作参考。
3. 在参考视频配置中准备同一角色的五段本地成片：待机、平静说话、答谢、招手、介绍。点击「使用现有视频创建角色卡」，本地去绿并整理为透明WebM，不调用付费生成。
4. 预览确认后应用。服装与表情表现取决于视频质量，淡化切换不能修复错误姿态或变脸。

本地整理仍需要FFmpeg与ffprobe，角色ZIP导入需要ffprobe。现有NVIDIA本地语音安装和音色包导入保持不变，见[本地语音组件说明](local-tts-component.md)。

## 数据与兼容

- 程序不删除已有scenes目录、原图、旧项目ZIP或角色卡。
- 旧项目包导入时保留人物图、背景、商品知识、规则和答谢模板；旧网格、绑定和旧动作配置不再执行。只有图片的旧项目必须配齐视频建卡后才能开播。
- 新项目包携带应用的角色卡；未建卡时携带准备图片。密钥、GPU环境和音色库不进项目包。
- 已移除旧`/api/scenes`制作/编辑接口；脚本调用者改用角色卡接口，语音测试使用`POST /api/characters/test-voice`。
- `tools/avatar_pipeline`作为独立研究CLI保留，不在客户端显示，也不会自动执行。

旧版章节和调研文档保留作历史记录，以本说明和当前代码为准。

## 本机验证

2026-11-27 Windows x64：62项Python测试、13项Node测试通过。开发版与目录版使用当前真实角色卡验证人物图/背景上传、真实Windows配音、角色ZIP导入切换、答谢/招手/介绍视频、礼物答谢与透明播出声音归属；旧页面和旧画布不存在。后台与Windows便携EXE已构建。没有调用付费生成服务；未重新验证本地NVIDIA实际推理、第二台机器和OBS现场推流。此机器缺少默认音色构建ZIP，因此本次EXE不内置音色权重，已安装环境保留，新的本地音色需要另行导入。
