# 极播 0.5 / 0.5.1：角色制作、成本与验收

本轮实现日期：2026-11-26。新路线为隔离的角色制作与OBS互动彩排，旧版场景仍可使用。尚未调用收费生成接口，尚未用目标角色、实际生成视频、实际语音和OBS完成整链路效果验收。

## 0.5.1 当前规则（优先于下方0.5初版记录）

- 已从新制作入口移除思考说话；旧数据文件与费用记录保留，旧包导入会忽略该素材。
- 基础五项：待机、平静说话、答谢、微笑招手、介绍手势。新介绍/招手已用当前透明正面角色生成并配置本机参考库，生成费估算共1元，5秒/480P各一段。
- 情绪说话选填。没有参考时不生成、不收取该项估算；没有成片时OBS回退平静说话。当前可选槽为开心说话，旧思考调用兼容回退。基础五项齐全即可验收、迁移和播出，不再强制凑齐七项。
- 可选情绪生成失败而基础素材齐全时允许验收，保留失败/未知费用记录，不自动重做；可选未知任务仍需到供应商后台查账，不代表没有扣费。
- 用户素材在数据目录中，EXE不含密钥或这些参考。新版便携EXE为`Jibo-Studio-0.5.1-win-x64.exe`，与已有`YingboData`放在同目录后会沿用它。
- 五段各3秒：标准约7.05元、专业约10.05元。当前本机五段各5秒：标准约11.05元、专业约16.05元。图片1元和GPT0.05元仍只是可调整预算，实际以供应商为准。
- 新参考的透明导出和实际Windows语音预览已制作；未把文件编码成功当作无缝切换或OBS现场验收通过，也未替换旧场景渲染器。

官方API：[万相图生动作](https://help.aliyun.com/zh/model-studio/wan-animate-move-api)、[临时上传协议](https://help.aliyun.com/zh/model-studio/get-temporary-file-url)。具体提交为`POST /api/v1/services/aigc/image2video/video-synthesis`，`input.image_url`、`input.video_url`，`parameters.mode=wan-std/wan-pro`；保存`output.task_id`，后续仅查询`GET /api/v1/tasks/{task_id}`。

播放复用：[obs-websocket-js](https://github.com/obs-websocket-community-projects/obs-websocket-js)，本地安装包的`dist/base-*.d.ts`包含`MediaInputPlaybackEnded`、`GetInputList`、`CreateInput`、`SetCurrentProgramScene`等协议。本项目通过API控制独立安装的OBS，没有复制OBS播放器源码、打包Wan推理代码/权重或引入CUDA。

这次没有采用新的自写视频渲染器。此前架构文档中的WebGL合成、独立背景与FFmpeg统一转码属于候选设计，**尚未在新路径实现**。新路径目前输出完整视频背景，不能当作已具备透明人物输出；绿色服装/不同背景需要后续真实样片验证后选定抠像方案。旧版透明播出窗口属于旧场景路径。

## 首次准备与最少操作

管理员首次配置：

1. 安装OBS Studio 28或更新版本，启用「工具 → WebSocket服务器设置」，记下本机地址和密码。
2. 安装FFmpeg，让`ffprobe`位于PATH，并重启客户端。当前EXE未附带FFmpeg；制作、导入时需要ffprobe，播放已有角色由OBS解码。没有工具时会在报价里列为缺项，阻止发起付费制作。可使用[FFmpeg官方下载入口](https://ffmpeg.org/download.html)选取系统对应发行版。
3. 在「接入设置」保存图片服务与TTS；在「角色制作 → 首次配置」保存GPT视觉和万相服务、费用预算、OBS密码。模型、API地址和密钥需属于同一地域/账户。
4. 配置七份**有权使用的参考表演**：待机、平静说话、开心说话、思考说话、点头答谢、招手、介绍。当前没有内置经过商用授权和质量验收的表演库。每份MP4长2–8秒、小于20MB；本地上传会读取实际时长，公网URL需如实填写。

参考表演应固定相机、构图和角色比例，首尾共同回位，待机/说话首尾能循环。说话参考需嘴部自然开合，同时有轻微呼吸、眨眼、头发与衣物活动；大幅动作要验证宽袖、下摆、开衩与肢体关系。答谢期间如果同时播放语音，参考表演也需有自然嘴部活动。万相迁移服装与表情的效果取决于角色与参考，GPT描述不等于衣物语义分割或物理模拟。

配置一次后，每个角色：上传图片 → 核对报价并确认生成 → 检查七段视频 → 确认验收 → 连接OBS并开始互动彩排。商品在「商品知识库」编辑，弹幕与礼物在「直播工作台」测试。OBS只会建立`极播-<角色编号>-<状态>`场景，不启动/停止平台推流，也不删除已有场景。软件会选择OBS节目场景和淡化过渡，请在非正式播出的OBS中验收。

实际声音来自极播客户端，OBS需配置桌面音频或应用音频采集；媒体视频静音以免双音轨。不使用逐字口型；“talk”等视频循环播放已有嘴部活动。开心/思考素材可手动选择，目前商品问答**没有自动情绪分类**。

## 单个角色制作成本

计价参考：[阿里云官方价格](https://help.aliyun.com/zh/model-studio/model-pricing)，2026-11-26北京地域原价。标准模式0.40元/秒，专业模式0.60元/秒，其他地域、渠道、优惠和后续调价以实际服务为准。

默认假设：七段各3秒，总计21秒；一次GPT角色分析预算0.05元；一张标准角色图预算1元。**后两项是可修改的估算值，不是GPT或gpt-image-2的官方固定报价**。不包括参考表演的拍摄/采购、背景制作、人工筛选和长期LLM/TTS。

| 项目 | 标准模式 | 专业模式 |
| --- | ---: | ---: |
| GPT分析预算 | ¥0.05 | ¥0.05 |
| 标准角色图预算 | ¥1.00 | ¥1.00 |
| 七段视频，共21秒 | ¥8.40 | ¥12.60 |
| 一次制作估算 | **¥9.45** | **¥13.65** |
| 额外预留整套视频重做一次后的总预算 | ¥17.85 | ¥26.25 |

若每段5秒，单次约15.05元/22.05元。计算式为`GPT预算 + 图片预算 + 视频总秒数 × 每秒单价`；输入参考时长越长费用越高。软件展示逐项报价、已完成估算与结果不明占用估算，保留任务编号、服务返回用量和实际视频时长。账本属于**估算记录**，无法代替服务商扣费账单或执行平台侧硬性封顶；本地预算只阻止后续新增请求。

“重做预留”只表示预算余量，**不会自动重做**。请求超时或退出若没有可靠任务编号，不重新付费提交；需先查供应商后台。有可靠视频任务编号时「继续」只查询原任务；账号、地址、模型或模式改变后禁止继续，需恢复原配置。明确失败任务也不会自动再次付费，本版没有局部收费重做按钮，避免误认为预留费用代表自动重试。

日常直播复用视频，不持续产生视频生成费。Windows系统TTS在本机生成/缓存，云TTS和问答按各自服务账单，电费与OBS运行消耗另算。32GB内存＋8GB显存不需要加载Wan大模型；当前没有在更低配置机器完成性能验收，不能据此承诺最低配置或长期稳定性。

## 迁移与打包

- 新便携版默认在EXE旁创建`JiboData`；同目录已有`YingboData`时继续使用它。关闭程序后复制EXE与完整数据目录，可保留所有角色/商品/设置；其中包含密钥，不应共享。
- 可在「角色制作」导出角色ZIP，再到新机器导入；不包括密钥、参考表演和未完成任务，导入只检查本地视频并重新验收。商品/规则通过顶部的项目包单独迁移。项目包目前不包含新角色库。
- Windows源码启动用`start.cmd`，打包用`build.cmd`。新包为`release/Jibo-Studio-0.5.0-win-x64.exe`，目录版为`release/win-unpacked/极播.exe`，目录版须整体复制。
- macOS/Linux必须在目标OS和架构上重新打包，独立安装OBS与FFmpeg；系统语音不可直接迁移。当前只在Windows实测。
- 若electron-builder下载Electron受网络影响，已安装开发依赖时可使用本机Electron：`npm run dist:win -- --config.electronDist=node_modules/electron/dist`。本轮Windows包使用了此构建参数。
- `ffprobe_binary`支持打包资源的`media-tools/ffprobe(.exe)`或系统PATH。当前构建脚本没有捆绑第三方FFmpeg二进制；正式附带时需选择适合商业分发的发行版、保留其许可并满足对应源码提供条件，不能把开发机的GPL完整构建无说明复制进EXE。

代码库的技术路线不等于整套素材的商业授权。`obs-websocket-js`是MIT；OBS/FFmpeg分别按各自发行版许可独立使用；万相为封闭云服务，服务条款、输入素材权利、生成内容使用条件独立确认；未分发Wan权重，不据此声称已解决其模型授权问题。

## 端到端验收清单

1. 用目标角色和已授权参考表演真实生成，检查侧身标准化、身份、衣物、手脚、表情与嘴部运动。
2. 用实际TTS播放待机→说话→开心/疑惑→答谢→待机，检查循环接缝、重影和声音结束回位。250毫秒淡化不保证姿态连续，首尾不匹配的素材要淘汰。
3. 用实际商品测试有关问题、无依据问题、屏蔽词、指令干扰、连续礼物；验证商品依据、跳过、优先队列与恢复讲解。
4. OBS断连、音频失败、停止/重开、程序退出重启应不重复播报、不重复提交付费请求。
5. 授权抖音弹幕/礼物采集器仍需单独接入已有事件接口；当前只有模拟事件与接口，不能算真实抖音端到端已完成。

自动化测试中的模拟服务响应和视频字节只验证软件协议/账本/生命周期；它们不是AI生成质量证据。当前开发版/打包版启动检查也不代替上述真实素材验收。


## 角色输入流程修正（2026-11-26）

用户提供的带背景原图只用于角色分析、正面标准化和背景素材提取，不应直接作为动作生成输入。已有正面透明资产应直接复用。本轮参考样片脚本已改为读取当前场景的`neutral.png`，缺少合格透明图时停止，不回退到原图。

新角色制作分支复用`scene_model`的标准正面提示词和`remove_chroma`：保存透明`standard.png`，再通过`video_input_image`为不支持透明通道的云API临时铺纯绿底，保存`video-input.png`。临时绿底不是恢复原始背景；云端普通MP4仍需后续抠像，不能宣称自动获得透明视频。角色包导入保留PNG透明通道。

本次已准备正确角色的`source.png`和`input.png`。实际视频请求被服务商HTTP 400账户状态/欠费检查拒绝，未获得任务编号，其余两个任务未提交。已停止，不自动重试。本轮源码修正尚未重新打包进现有0.5.0 EXE。


### 充值后本轮样片结果

用户明确要求重试后，正确正面透明图的三段视频均生成成功，每段5秒、480P档，实际624×624/30fps；原始绿幕MP4及经FFmpeg chromakey/despill处理的透明VP9 WebM均保留。逐段实际解码确认alpha为0至255，提供三路灰底对照预览。新三段估算1.50元，连同前一轮两段成功视频约2.50元，未超过累计3元预算。旧账户拒绝已保留历史，新请求不重复提交已有任务。

样片位于`release/YingboData/reference-samples/20261126-7d64f11ab271/`。待机末尾张嘴、说话末尾未闭嘴、答谢动作偏离手位提示、首尾姿态差异均未被隐藏；当前只作人工验收候选，未写入默认参考库或改造正式播放器，未完成实际TTS/OBS衔接验收。
