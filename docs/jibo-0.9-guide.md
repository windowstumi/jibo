# 极播0.9：新版工作空间

## 第一次拿到软件

软件默认打开「开始使用」，依次完成四项准备。每张卡片和页面上方的下一步按钮都能直达对应功能。

1. **准备角色**：进入「角色中心」，已有角色ZIP时直接导入。选择角色，在预览中检查动作，确认验收并应用。没有角色时，可展开现成素材建卡入口，或展开「从图片生成新角色」按提示配置云端制作。
2. **配置声音**：进入「设置中心 → 声音与音色」。Windows上可以先用系统配音；克隆音色需安装本地组件、导入音色包并加载。然后在角色中心的语音预览中实际试听。安装好组件不等于已经拥有可用音色。
3. **添加商品**：进入「商品知识库」，填写真实商品资料、常见问答和讲解稿。示例商品可以用于验证，但不会被准备向导当成真实商品配置完成。
4. **检查互动**：进入「互动与守则」，确认屏蔽词、聊天范围和礼物感谢文案。默认商品问答；允许自由聊天时需云端模型，角色性格在角色中心配置。

最后进入直播工作台：点击开始彩排以播放商品讲解；或直接在「弹幕与礼物测试」发送测试事件，自动进入仅互动预览。确认字幕、语音和动作后，再使用透明播出窗口或OBS接入直播软件。

「已配置」表示检测到对应的配置、素材或启用规则，不代表已经实际试听或完成现场推流。系统配音和外部语音接口仍需试听；本地音色只有所选音色真正加载就绪时才显示已配置。

## 功能在哪里

| 页面 | 日常用途 |
|---|---|
| 开始使用 | 当前工作空间、准备状态、下一步入口 |
| 直播工作台 | 角色与商品选择、彩排、字幕语音与动作、测试弹幕和礼物、互动记录 |
| 角色中心 | 导入/切换角色、角色设定、动作与语音预览、验收应用、导出角色卡、按需新建角色 |
| 商品知识库 | 商品资料、FAQ、讲解稿及AI整理 |
| 互动与守则 | 是否允许聊天、屏蔽规则、礼物感谢文案 |
| 设置中心 | 下面六类服务、外部接入及迁移 |

## 设置中心

| 分类 | 内容 |
|---|---|
| 声音与音色 | Windows/本地/兼容接口选择，本地组件安装、音色导入加载与试听 |
| AI大模型 | 问答/聊天模型、地址和密钥；链接到互动范围设置 |
| 图片服务 | 图片重绘接口、密钥、图片代理和连接测试 |
| 角色生成 | GPT视觉、万相视频、生成服务代理、折叠预算、动作素材库 |
| 直播接入 | OBS地址/密码、外部原生场景操作、平台事件接口与说明 |
| 数据与迁移 | 项目导入导出、数据目录及角色单独迁移入口 |

声音/AI/图片继续复用原有服务配置表单，生成/OBS继续共用原有制作配置表单；同一字段没有重复的第二份。切换分类不会重建输入框，因此未保存输入仍保留；修改后须点击保存。不同表单各自显示保存按钮。导入角色ZIP在角色中心，导入整个项目在数据与迁移，音色包在声音与音色。

生成服务和OBS均是按需配置，已有角色卡、本地预览和基础知识库问答不要求先填写所有云端服务。云端制作的费用确认、预算限制与不自动付费重试保持原有机制。

## 界面与兼容

采用蓝黑底、青蓝强调色和高对比文字，侧栏区分创作与管理，状态同时使用文字和颜色。界面不依赖在线字体或图片库；复用浏览器原生表单、网格布局和现有Electron，不添加UI框架、GPU推理或新模型。设置分类支持方向键和Home/End，控件保留标签及键盘焦点提示，并遵循减少动画的系统偏好。

已有项目、角色、商品、密钥、音色和运行环境继续使用，无需迁移数据库或重新生成。升级时退出旧客户端，保持原来的数据目录，在原目录打开新版便携EXE。透明播出画面的角色素材、背景、字幕和声音队列继续使用原有实现。

## 验证

0.9界面在实际Electron中检查默认首页、下一步路由、六类配置显隐与保存、未保存输入保持、示例商品与错误音色不标记就绪、无重复ID/嵌套表单，以及常规和约984px窗口下各页面无横向溢出。已有76项Python、16项Node功能回归通过。验证数据使用隔离副本；不改用户的真实配置、不下载/训练模型、不调用付费生成服务。
