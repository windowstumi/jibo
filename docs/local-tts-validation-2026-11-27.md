## 实际使用的音色和接口

使用原有 `GPT_weights_v2/cao-e15.ckpt` 与 `SoVITS_weights_v2/cao_e8_s184.pth`，版本仍为 **v2**。参考文件是原有 4.5 秒 WAV，文字来自同包已有标注。测试没有向外上传录音。

- 官方 API：`http://127.0.0.1:9880/tts`。
- 极播兼容适配：`tools/local_tts/gpt_sovits_bridge.py`，监听 `http://127.0.0.1:9881/v1/audio/speech`。
- 适配只转换接口、固定参考音频和返回 PCM WAV；推理仍由上游实现。单请求工作，不自动重试。
- 本机配置、试听和结果保存在忽略目录 `data/local-tts-check/`，不进入 Git。
- 通过隔离数据目录调用极播原有 `app.synthesize`；未修改用户当前保存的 TTS 配置或角色卡。

已有 0.6.2 便携 EXE 的配置：语音服务选兼容接口，地址 `http://127.0.0.1:9881/v1`，模型 `gpt-sovits`，音色 `cao`，密钥填占位值 `local`。旧版空密钥会产生非法 `Bearer ` 请求头；源码已修复为空密钥时省略该请求头，但本轮没有重新编译 EXE。

整合包目录新增 `go-jibo-local-tts.cmd` / `.ps1`，启动官方 API 与适配服务，已运行时复用；后台日志在 `updates/service-logs/`。该启动器针对本机现有两个目录，不随极播 EXE 自动运行。单独启动官方接口也可运行 `go-local-api-updated.cmd`。

## 测量结果

机器：Ryzen 5 5600、32GB 内存、RTX 5060 8GB、Windows 10 x64。以下时间是 **完整 WAV 收齐耗时**，不等于首音频延迟，不包含模型启动时间；本轮没有同时开启 OBS 做推流性能验收。

| 调用 | 音频时长 | 合成/调用耗时 |
| --- | --- | --- |
| 旧版预热后答谢 | 4.16 秒 | 1.914 秒 |
| 新版预热后答谢 | 4.28 秒 | 2.011 秒 |
| 新版预热后商品介绍 | 9.66 秒 | 2.775 秒 |
| 新版预热后短欢迎语 | 2.94 秒 | 1.349 秒 |
| 经极播 `app.synthesize` 的新介绍 | 8.02 秒 | 3.548 秒 |
| 极播相同文本缓存命中 | 同一文件 | 约 0.0002 秒 |

新版首次请求约 20.85 秒，旧版首次约 52.06 秒，均有初始化影响，不能当作稳定性能比较。上述样本不证明新版一定比旧版快。

极播请求期间采样到整卡总显存峰值约 3422MiB，包含桌面及其他应用；不是模型净显存需求，不能据此直接声明 4GB 显卡可稳定直播。

已检查 PCM WAV 可解码、有非静音信号，已验证未知音色返回 400、旧 EXE 的 `local` 占位密钥可调用。音色相似度、自然度及商品名发音由试听进一步验收，不能仅凭波形认定质量合格。

修改后 **64 项 Python 测试通过**，含空密钥本地 TTS 及有密钥服务回归。本轮未重新执行角色视频视觉验收、第二台机器测试或商业分发许可确认。
