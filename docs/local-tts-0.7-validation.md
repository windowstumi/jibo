# 极播0.7.0本地语音验证

日期：2026-11-27。系统：Windows 10 x64，Ryzen 5 5600，32GB RAM，RTX 5060 8GB。

- 使用全新的项目内Python 3.11.9虚拟环境，安装锁定的官方PyTorch 2.8.0+cu128及推理依赖；没有继承旧整合包的Python包路径或目录联接。
- 官方PyTorch的约3.2GiB wheel及G2PW发音模型执行实际网络下载、分段和SHA256校验；上游源码和BERT/HuBERT使用已有下载缓存，逐文件SHA256匹配固定发布文件。NLTK资源通过固定提交的官方GitHub API下载校验。
- 默认音色包使用用户声明授权分发的现有模型对和参考录音，经过真实包导入校验。导入目录、文件哈希、重复音色独立ID及错误包拒绝有自动回归。
- `check.cmd` 通过70项Python测试、17项Node测试和开发版真实Electron启动检查。
- 开发版、目录版及最终便携EXE使用真实NVIDIA语音组件，验证自动加载、可见进度窗口、预热、设置页试听、音频实际解码播放、重复文本缓存和退出后服务回收。
- 最终便携EXE验收前移除了此前测试生成的同一WAV，确保第一次试听重新合成：音频7.46秒，合成并开始播放约3.47秒；随后相同文本缓存调用约0.004秒。
- 验证包含USB英文缩写和价格的实际台词，离线发音资源已纳入安装，预热包含英文示例以避免首次直播时再初始化。
- 主EXE为341762228字节（约325.9MiB），包含默认音色ZIP；GPU环境与公共模型在首次启用时下载。成功预热后清理约3.8GiB安装归档，当前组件按唯一文件计约9.73GiB。建议首次安装预留15GB以上空间。
- 资源目录包含第三方声明和许可文件。代码和用户录音的授权分别记录，未将录音权利与上游代码许可混同。

本次未在第二台物理机器、低配客户机或OBS现场推流中验证，也未重新调用云图片/视频/语音收费接口。普通安装依赖网络与NVIDIA驱动，已完成安装的语音运行不需要联网。音色自然度、品牌/数字读音仍应使用具体商品台词试听验收。

机器可读结果、截图与安装日志保存在忽略目录 `data/local-tts-check/`、客户端数据目录和 `release/build-validation-0.7.0.json`。代码和环境说明见 [组件使用说明](local-tts-component.md)。
